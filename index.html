    📘 Teacher & Student Guide

    This is a full learning path with 120 different lessons in 15 units, from beginner HTML to advanced CSS and full website projects. All teaching text uses simple English.

    120Lessons with quizzes and homework
    15Learning units

    How to teach one lesson (about 40–55 minutes)

    • 5 minutes: Read the lesson goal and explain the new word.
    • 10 minutes: Read “Your teacher explains” and “Understand the example code”.
    • 15 minutes: Students change the example, run it, and discuss the result.
    • 5 minutes: Students answer the quiz and explain why.
    • 10–20 minutes: Start the homework; finish it after class.

    How students use the website

    • Start at Lesson 1 if you know nothing about HTML or CSS. Open HTML and CSS editor tabs to change the code.
    • Press Run Code to see the result. Ctrl + Enter also runs code.
    • Use Desktop / Mobile to compare layout at different sizes.
    • Check the practice box only after testing the code, answer the quiz, and finish the homework. Then select Complete this lesson.
    • Download your HTML to keep a copy. Download your progress as a JSON file to give to your teacher.
    • All lessons and preview work offline. Save this HTML file. Progress is stored only on this browser/device, not sent to a teacher.

    Important limits

    The quizzes check one key idea per lesson. They are learning checks, not formal exams. Homework is self-marked and should be reviewed by a teacher. Real forms need a backend to send information. Publishing to the internet needs hosting. Advanced mastery needs many independent projects beyond this course.

    Teacher assessment idea

    Check each project for clear HTML meaning (25%), working CSS layout (25%), mobile and keyboard usability (20%), readable organized code (15%), and student explanation of their work (15%).
