Web Academy — Teacher's Guide

120 HTML + CSS lessons • 15 units • Very simple English • Independent practice in every lesson.

Suggested teaching routine

  1. Start by asking what students already know about the lesson topic.
  2. Read the simple concept and explain it using a real-life example.
  3. Read the code explanation together. Ask the class to predict the result.
  4. Students edit, run, make one mistake deliberately, then correct it.
  5. Students take the quick quiz and explain the answer.
  6. Assign the homework. Review the actual code, not only the “homework finished” checkbox.

How to assess project work

HTML structure & meaning 25%; CSS design and layout 25%; responsive and keyboard usability 20%; code clarity 15%; student ability to explain the page 15%.

Offline information: The lessons and code runner are self-contained. Work and completion data are local to each student’s device. Use the “My Progress” export to collect student reports. This does not send homework to a server and there are no student accounts.
