WEB ACADEMY — HTML + CSS FROM ZERO TO PRO

START HERE:
1. Double-click index.html (or Web_Academy_Zero_to_Pro.html) to open in Chrome, Edge, Firefox or Safari.
2. Start with lesson 1. Each lesson has easy English teaching, step-by-step instructions, a code explanation, practice, a quiz and homework.
3. Edit the HTML or CSS tab, then press Run Code to see your page.
4. Complete practice, quiz and homework to mark the lesson complete.
5. Click Download HTML to save your page. Click My Progress to export your work as a JSON report to share with your teacher.
6. No internet, login, server or external app is required to read lessons or run HTML/CSS.

TEACHER NOTES:
- 120 lessons organized into 15 units, eight lessons per unit.
- Suggested teaching: Explain (10 min), code demonstration (10 min), student practice (15 min), quiz (5 min), begin homework (10 min).
- A student may mark homework complete, but a real teacher should review the actual work.
- Work is saved to the browser on THIS device (localStorage) where permitted. Different browsers/devices do not automatically share progress. Avoid private/incognito mode if you need to retain it.
- For class collection, ask students to download their progress JSON and their HTML project files.
- The site is a static file. To give learners a public URL, upload index.html to a static host such as GitHub Pages or Netlify.
- The course teaches HTML and CSS from foundational to advanced topics but practice and feedback on real projects are still needed for professional skill.

NOTE TO STUDENTS:
The code preview is intentionally sandboxed. JavaScript, sending form entries, and some cross-site navigation are not enabled. You can still practise HTML and CSS.
Images, links and media hosted on the internet need an internet connection. The course lessons and their text are fully offline.

راهنمای کوتاه: فایل index.html را در مرورگر باز کنید. هر درس توضیح، تمرین، اجرای کود، سوال و کارخانگی دارد. پیشرفت شاگرد فقط در همان مرورگر ذخیره می‌شود. برای جمع‌آوری کار شاگردها، فایل پیشرفت و پروژه را دانلود کنید.
